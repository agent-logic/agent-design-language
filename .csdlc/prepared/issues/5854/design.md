# Demonstration, Handoff, and Publication Sprint Design

## Purpose

Coordinate WP-17, WP-18, WP-18B, WP-19, WP-20, and the remaining WP-24A
episode checkpoints while preserving the terminal WP-24 result and preventing
private production artifacts from becoming release claims.

## Execution Contract

- Treat WP-24 as terminal and do not reopen its implementation path.
- Continue WP-24A as separately reviewed, non-closing episode checkpoints;
  episode 001 is complete and episodes 002-010 remain.
- Run migration semantics, birthday proof, and governance handoff after WP-16.
- Run provider-neutral proof only after protocol and birthday dependencies.
- Converge all demos and coverage in WP-20.
- Finalize public claims only after WP-23 release truth and explicit operator
  authorization.
- Bind each unbound child in a dedicated FastWork worktree with the company
  code repository recorded by typed C-SDLC v2.

## Non-Goals

- External publication from the umbrella.
- Synthetic demos or topic-only publication placeholders.
- Treating a deferred validator, merged checkpoint, or private archive as
  acceptance proof for its parent issue.
