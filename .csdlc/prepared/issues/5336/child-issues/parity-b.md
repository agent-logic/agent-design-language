## Goal

Make Runtime v3 reasoning graphs, bounded loops, adaptive learning, and
governed cognition executable through the real kernel path while preserving
all retained feature boundaries.

## Owned Capability Groups

- reasoning graphs, loops, adaptive DAGs, and policy-governed mutation;
- affect reasoning-control and safe non-claims;
- curiosity/discovery and theory-of-mind boundaries;
- Constructability, Godel mechanics, guild, economics-context, and skill
  standard feature preservation.

## Required Outcome

Submitted graphs execute through canonical ingress with deterministic
replay/resume, bounded termination, signed one-shot mutation authority, durable
evidence, and rollback. Governed cognition resists adversarial task-content
steering and cannot bypass Freedom Gate, shutdown, or review authority. Every
owned feature receives a Runtime v3 implementation or explicit accepted
non-runtime/boundary disposition before Runtime v2 deletion.

## Deliverables

- Live graph/loop/adaptation integration proof.
- Adversarial affect/curiosity authority and monotonicity proof.
- Feature-preservation dispositions for every owned feature row.
- Deletion of duplicate reasoning implementations.

- Production code is exercised through `adl-runtime-kernel`; fixture,

  revision.
