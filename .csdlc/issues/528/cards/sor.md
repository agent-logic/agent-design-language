## Execution

- Added first-class vertex_ai_gemini provider dispatch with vertex_ai and vertex aliases mapped through the HTTP transport substrate.
- Implemented regional Vertex AI generateContent endpoint construction from explicit project, location, and provider_model_id values, with bearer auth sourced only from a configured environment variable.
- Rejected plaintext remote endpoints and untrusted custom HTTPS endpoints before credential use, while allowing loopback endpoints for deterministic local harness tests.
- Parsed Gemini generateContent candidate text responses and recorded sanitized native invocation evidence under the vertex_ai_gemini family.
- Added semantic provider-kind validation, a Vertex AI Gemini profile preset, and focused local tests covering request shape, response parsing, endpoint safety, missing-token redaction, and provider registry dispatch.
- Added a focused assertion that vertex_ai:gemini-2.5-flash remains a first-class vertex_ai_gemini profile with no generic HTTP endpoint fallback.
- Added Vertex request-body construction that maps UTS-style config.tools entries into Vertex functionDeclarations.
- Normalized Gemini functionCall response parts into Provider output JSON that preserves tool-call names and arguments.
- Added an explicit Vertex streaming path using streamGenerateContent and callback emission.
- Added focused regressions for UTS tool declarations, returned argument preservation, and streaming callback behavior.
- Added shared HTTP response/text helpers so streamGenerateContent responses can be consumed as framed text instead of one JSON object.
- Parsed JSON, JSON-array, SSE data, and line-delimited JSON Vertex streaming frames, invoking the stream callback per extracted chunk and preserving aggregate output.
- Added Vertex auth modes for explicit bearer env, ADC via gcloud auth print-access-token, and workload identity metadata token retrieval, with explicit env-token override preserved.
- Added deterministic regressions for multi-frame Vertex streaming and ADC command token acquisition through a worktree-local mock gcloud executable.
- Deleted zero-byte .lock files generated by earlier provider receipt tests from issue-owned evidence.
- Updated the Vertex receipt test to remove its invocation lock sidecar after removing the receipt.
- Updated the ADC mock-gcloud test to remove its worktree-local mock executable and directory after the test.
