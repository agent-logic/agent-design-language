# GCP Six-Resident Qualification

The GCP sidecar repeats the distributed Runtime six-resident workload and continuity proof on a provider-specific GCP environment. It must preserve exact resident identity and lineage, use separate GCP account/project/billing/credential controls, retain cost and cleanup evidence, and prove zero residual resources.

Planning grants no paid-run authority. AWS and GCP receipts are compared for portability, not treated as interchangeable authority.
