# Provider Inference Profiles

This track defines one shared provider-profile mechanism used consistently by ADL tools. Profiles bind provider/model identity and bounded inference parameters, validate before activation, support deterministic Ollama materialization, preserve last-known-good behavior, and expose provenance without credentials or prompts.

The second package runs local-model shadow comparisons without granting authority to shadow output. MLX/Metal and OCI model packaging remain deferred.
