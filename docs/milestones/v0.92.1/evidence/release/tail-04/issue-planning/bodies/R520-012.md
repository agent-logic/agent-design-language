## Summary

Remediate P2 finding `D520-DOC-002` from internal review #520 by providing separate truthful reproduction routes for the immutable TAIL-02 historical handoff and its linkage from the current release candidate. At reviewed candidate `c24f8fa65ce445b03ce6cd69007307291d78b60c`, the first documented TAIL-02 command exits with `current inventory denominator changed; refresh required` because it compares a frozen historical inventory to a repository that has legitimately grown.

## Goal

Make the documented TAIL-02 handoff reproducible without rewriting immutable historical hashes or pretending that historical and current-candidate checks own the same denominator.

## Required Outcome

One documented command verifies the historical source-head handoff at its immutable boundary, a separate candidate-safe command verifies current linkage to that handoff, and both commands succeed for the claims they actually own after later tracked files are added.

## Deliverables

- A historical source-head verification mode in `.csdlc/prepared/issues/518/validate-documentation-handoff.rb` or an equivalently bounded validator.
- A current-candidate linkage verification mode that does not recompute the historical inventory as if it were current.
- Updated TAIL-02 reproduction instructions in `docs/milestones/v0.92.1/evidence/release/tail-02/README.md`.
- A regression fixture proving later repository growth does not invalidate immutable historical evidence.
- Proof that TAIL-03 still binds the original TAIL-02 content and hashes.

## Acceptance Criteria

- Historical source-head verification and current-candidate linkage verification are explicit, separate operations.
- The first documented command no longer fails merely because unrelated tracked files were added after the historical handoff.
- Each command's output states the candidate/source identity and denominator it actually verifies.
- Immutable historical hashes and inventory are not rewritten to match repository growth.
- A clean detached historical checkout and a clean detached current-candidate checkout both reproduce their respective claims.
- TAIL-03 linkage continues to bind the original TAIL-02 content.
