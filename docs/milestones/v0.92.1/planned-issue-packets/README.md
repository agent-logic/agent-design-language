# Preserved v0.92.1 Planning Packets

This directory preserves the detailed cards, designs, diagrams, validators, and
draft proof entrypoints authored during issue `#146`.

These files are planning inputs only. They are deliberately outside the live
`.csdlc/issues/`, `.csdlc/prepared/issues/`, and `adl/tools/` execution roots.
They do not represent open issues, approved designs, executable validators,
completed proof, or lifecycle authority.

Issues `#149-#190` were retired without execution. Future WP-01 must create new
issues from the reviewed execution specifications, regenerate current cards and
designs through the active templates, and validate them before binding. WP-01
may consult this archive so none of the planning work is lost, but it must not
copy stale lifecycle state or treat the retired issue numbers as authority.

## Contents

- `issues/`: preserved six-card packets and audit projections for the retired
  issue numbers.
- `prepared/issues/`: preserved designs, diagrams, and draft outcome validators.
- `proof-stubs/`: preserved draft distributed-proof entrypoints.
- `manifest.json`: exact source-to-archive paths, byte counts, and SHA-256
  digests for all 721 preserved files.
