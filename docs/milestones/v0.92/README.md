# ADL v0.92

v0.92 is the completed first-birthday and resident-runtime milestone for Agent
Design Language.

The milestone delivered the bounded runtime, identity, continuity, memory,
capability, adaptive-learning, governed-tool, provider-neutral, Observatory,
demo, evidence, and review work defined by its issue wave. This directory is
the durable record of that work.

## What v0.92 Establishes

- stable resident identity and continuity across bounded runtime cycles
- grounded memory, Memory Palace context, capability, and witness authority
- implemented Runtime-kernel production-authority slice for Memory Palace
  context packets, with `adl-runtime-kernel::memory_palace` as the production
  authority for the bounded kernel slice
- governed resident tools, cognitive profiles, and adaptive learning
- provider-neutral multi-agent and distributed-runtime proof
- first-birthday execution, evidence, demo, and governance handoff
- reviewable Observatory and external-consumer boundaries
- canonical quality, documentation, publication, and milestone handoffs

## Claim Boundary

v0.92 is an engineering milestone. It does not claim legal personhood,
consciousness, unrestricted autonomy, public deployment, or completion of work
assigned to later milestones. External publication remains separately
authorized by its recorded publication gate.
