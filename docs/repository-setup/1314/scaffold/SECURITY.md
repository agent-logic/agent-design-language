# Security

This repository is private. Report suspected vulnerabilities through an existing
private channel to the Agent Logic repository owners; do not publish exploit
details, secrets, or private data in a public issue. Include affected revisions,
a minimal sanitized reproduction, and the observed impact.

No disclosure response time or product security qualification is claimed by this
scaffold. Repository privacy is not a substitute for credential hygiene, review,
or tests. Never commit credentials or production data. If a credential is exposed,
notify its owner privately and arrange revocation through the approved process.
